# Grey literature synthesis
 
The project helps process and search UN evaluation reports, working with a local copy of the UNEG database. It is useful if you want to search / analyse any sort of grey literature dataset where you have a large amount of very long PDFs.
 
## Table of Contents
 
- [About](#about)
- [Features](#features)
- [Installation](#installation)

## About
 
This project is developed as part of the effort to synthesise relevant evidence in the context of climate and health. Grey literature presents a unique problem as it is often poorly catalogued and includes large numbers of long documents (in multiple languages, with different structures, missing files, etc.). However, it also contains unique evidence on barriers and facilitators of interventions, which is of particular interest to interest-holders.
 

## Features
 
- Translate files into english
- Boolean search within texts 
- Embedding of paragraphs/sections/section titles

## Installation
 
This project uses [uv](https://docs.astral.sh/uv/) for dependency management and virtual environments.
 
```bash
# Clone the repository
git clone https://github.com/username/project-name.git
 
# Navigate into the project directory
cd project-name
 
# Install dependencies (creates a virtual environment automatically)
uv sync
```
